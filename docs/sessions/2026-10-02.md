## Перед push — инструкция

1. Локально: `hugo server` → пройтись по EN и RU, мобильному меню, контактам, legal.
2. `hugo --minify --gc && python3 scripts/qa.py` — должно быть «0 errors».
3. GitHub → репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**. (Без этого после push сайт отдаст 404 — в корне ветки больше нет index.html.)
4. `git push origin main`.
5. GitHub → Actions → дождаться зелёного «Deploy Hugo site to GitHub Pages».
6. Проверить https://www.ankosoftlab.com (и `/ru/`), что в Settings → Pages Custom domain = `www.ankosoftlab.com`, HTTPS включён, и что https://www.ankosoftlab.com/CNAME отдаёт `www.ankosoftlab.com`.
7. При проблеме: Actions → «Run workflow» вручную, либо временно вернуть Source на branch и `git revert` (старый index.html есть в истории, коммит `9e9f3ea`).
